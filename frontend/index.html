Estructura

Arquitectura del Sistema

01. CAPTURA

Cámaras IP y flujos RTSP ubicados en los torniquetes.

02. MOTOR IA

Servidor GPU procesando YOLOv8n-pose a +30 FPS.

03. BACKEND

API en Flask gestionando la lógica, SQLite para persistencia y logs.

04. FRONTEND

Dashboard SPA protegido por RBAC, WebSockets y reportes en tiempo real.

Stack

Tecnología de Vanguardia

YOLOv8 & OpenCV

Núcleo de inferencia utilizando PyTorch para identificar el esqueleto humano con alta precisión y bajos milisegundos de latencia.

Flask & Python 3.10

Framework robusto sirviendo la API REST, autenticación JWT emulada y gestión segura de eventos registrados.

Vanilla SPA & Tailwind

Interfaz ultraligera, router personalizado por History API, asíncrona y modular sin necesidad de dependencias pesadas en el navegador.
