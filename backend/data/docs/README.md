# Base de Documentación Autorizada de ARGOS - SiViA

Este directorio contiene la documentación oficial y autorizada del sistema ARGOS - SiViA (Sistema Inteligente de Vigilancia y Alerta).
Es consumida exclusivamente de forma local por el asistente Hermes para responder consultas conceptuales y arquitectónicas de los usuarios autorizados.

## Estructura de Documentos
- `arquitectura.md`: Arquitectura del software, componentes, backend ASGI y base de datos.
- `flujo_deteccion.md`: Pipeline de procesamiento del motor de visión artificial Athena.
- `conceptos.md`: Glosario técnico y operativo de cámaras, eventos, métricas de confianza, evidencias y RBAC.

## Política de Seguridad
Esta documentación es la única fuente autorizada para consultas conceptuales internas. Hermes no debe generar ni asumir detalles operativos que no estén respaldados en estos documentos.
